## 0. Correction made to three Phase 4 signals before fusing

Phase 4's portfolio concentration, district-authority pattern and temporal anomaly signals gave every work of an MP / authority the score of that entity's single most extreme work type or week. A work in an ordinary category inherited another category's outlier score, which pushed almost every work to ~1.0 and would have made any fusion meaningless. Each score now attaches to the work's own (MP, type), (authority, type) or own week, as BLUEPRINT §6's "each score attaches to its own row" requires. The district amount component was also moved to the log scale (it compared raw rupee means). This was done for correctness, not to shape tiers; regression tests pin each change.

| 4 | 18,442 | 18.9% |
| 5 | 44,015 | 45.1% |
| 6 | 30,829 | 31.6% |

Why so many works have many active signals: the scores are not calibrated. Each z-based signal maps its z to a score as if z were standard normal. If that held, a score >= 0.9 would occur for about 10% of works for a two-sided single z (cost, portfolio). It would be about 19% for district, the larger of two z's, and about 5% for temporal, which is one-sided. Observed:

| signal | score >= 0.9 | score >= 0.99 | normal-model reference |
| --- | --- | --- | --- |
| cost_anomaly | 18.7% | 10.6% | ~10% |
| near_duplicate | 12.4% | 9.3% | n/a (cosine, not a z) |
| portfolio_concentration | 46.6% | 31.3% | ~10% |
| district_authority_pattern | 47.4% | 28.3% | ~19% |
| temporal_anomaly | 59.4% | 46.4% | ~5% |
| lifecycle_delay | 40.5% | 20.5% | n/a (exceedance mix) |

Portfolio, district and temporal are far heavier-tailed than the normal model assumes. MP portfolios are overdispersed across 115 types, and MPs routinely recommend many works in one week, so a work's own week is usually busy. BLUEPRINT §6 lists calibrating signals to tail probabilities as a gated policy change, so it was NOT done here. This is the main reason both configurations fail K4 (section 8).

Known-defect fixture: five base signals at 0.9, cost anomaly (the heaviest) not evaluated vs evaluated at 0:

## 8. Proposal and justification

| criterion | v3-compatible | v4-candidate |
| --- | --- | --- |
| K1 Not-evaluated signal is not scored as 0 | FAIL | PASS |
| K2 Weight stability (top-1000 overlap median >= 80%, P5 >= 70%) | PASS | PASS |
| K3 CRITICAL reachable for >= 95% of works with >= 3 evaluated signals | PASS (97.2%) | PASS (100.0%) |
| K4 HIGH + CRITICAL <= 20% of works | FAIL (59.8%) | FAIL (59.1%) |
| K5 Corroboration counted once | FAIL | PASS |

Neither configuration meets every criterion, so neither is proposed as default.
- v3-compatible fails: K1, K4, K5.
- v4-candidate fails: K4.
Both fail K4 for the same reason: the fused inputs are not calibrated (section 3), so most works carry four to six active signals and most land in HIGH or CRITICAL under either formula. Choosing between the formulas does not fix this. The fix is signal calibration, or a change to the thresholds justified by this evidence. Both are gated decisions for you, not made here.
Weight stability: v3 top-1000 overlap median 96.2% (P5 88.4%); v4 median 97.3% (P5 95.7%).
Limits: no labelled outcomes exist at this gate. None of these numbers shows which configuration finds more genuine problems; that needs BLUEPRINT §12's injection curves, labelled duplicate set and audit sample. Tier thresholds and the CRITICAL >= 3 rule were not changed in this phase. If K4 fails, the tier distribution is reported as it is, and changing the thresholds is a separate decision that needs this report's evidence.
